Your history is a tangle. Git, with a little dark magic.

Your 1 GB Electron client called. It's embarrassed. gitmoire is a Git client that opens in under five seconds (GitKraken took me nearly forty), and has never once asked you to log in. The v0.14.2 downloads run from 14.9 MB on Windows to 90.2 MB for the Linux AppImage.

Get gitmoire See the graph Read the changelog

Free. macOS, Windows, Linux. Builds are unsigned, so your OS will ask once and be dramatic about it.

I respect your SSD.

Every Git client I tried was a website wearing a trench coat.

Slow to open, a gigabyte on disk, and a login screen standing between me and a typo fix. Insulting. gitmoire runs Git on Rust and libgit2 instead of a pile of shell scripts, so a hundred thousand commits scroll like fifty.

And it's ready before the kettle is.

GitKraken took me almost 40 seconds to open. gitmoire opens in under 5. That's not a benchmark suite, it's me waiting for a window on my own machine, which is the only benchmark that has ever annoyed me.

Virtualized, so it never hiccups. Drag a branch onto another to merge or rebase. Paste a hash and it jumps. Picked the wrong branch? CtrlZ. You're welcome.

    

  



  
  

    

      
Built for the daily loop.

      
Stage, commit, branch, merge, push. The parts you touch all day, done properly and kept out of your way.

      

        
conflicts

          
Both sides, with line numbers. One checkbox takes a whole side, hover-plus takes a single line, and the result pane is a live editor. Nothing touches your files until you hit Mark resolved.

        
worktrees

          
A second checkout in a sibling folder for the hotfix, or for your AI agent, while your real work sits untouched. There's a manager, an install script that runs in every new one, and a hue each so six don't blur together.

        
working copy

          
Stage files, hunks or single lines. Commit, amend, revert, reset, interactive rebase, cherry-pick one or fifty, stash (even partially), tags, submodules, hooks. Inline or split diffs, blame, file history.

        
remotes and forge

          
Fetch, pull and push over SSH or tokens, with multiple accounts per host. Pull requests for GitHub, GitLab and Bitbucket: list, checkout, create, pick reviewers. Bitbucket Server and Azure DevOps get read-only detail. Signing reads your git config and just works.

        
stash and wip

          
Stashes and your work in progress are first-class nodes on the graph, not a drawer you forget about. Right-click one to apply, branch from it, or drop it (after it asks).

        
palette actions

          
Teach the palette your own commands, per repo or everywhere, and run them in a terminal tab or quietly in the background. It's a task runner that already knows which repo you're in.

        
quick commits

          
Save a commit message once, reuse it forever from the palette.

        
yours

          
Identity profiles live in your repo config, never your global gitconfig. Tokens live in your OS keyring. Nothing phones home, because there is nothing to phone home to.

      The agent view, and the rest of the crew
      
      
      
        
      
          
      One screen for every session.
      
          
      Across every repository and worktree. Claude Code, Codex, Gemini, OpenCode, Cursor Agent and Antigravity are found automatically, and each one runs in a real terminal.
      
          
        
            
      • Readable at a glance. Every tab and sidebar row wears its repository's logo and colour, and a wizard avatar of its own, so a stack of terminals doesn't turn into soup.
        • 
            
      • Follows the repo you pick. The sidebar shows that repository's worktrees, running sessions and a mini commit graph, and collapses with CtrlB.
        • 
            
      • Sessions you can keep. Rename one, archive one, or resume yesterday's from the Previous list. A bell or an exit raises a toast.
        • 
            
      • Split and paste. CtrlShiftD puts a fresh shell beside the agent. Paste a screenshot and gitmoire saves it, keeps it out of your changes, and types the path for you.
        • 
          
      
        
      
        
      
      
      
        
        
      • They talk to each other. Agents coordinate through gitmoire agent start|notify|inbox|wait|plan|status. done, waiting and blocked show up as tab badges and toasts.
        • 
        
      • Pick a model per role. Planner, feature developer and reviewer each get their own provider and model, in Settings → AI or per run. The model menu lists what each CLI actually reports.
        • 
        
      • Bring the skill. A bundled gitmoire-orchestration skill installs for Claude Code from the dialog.
        • 
      
      
    
      
  
      


  
  
      
    
      
      
      
        
      AI, strictly opt-in
      
          
      Off until you turn it on. Then it borrows your own Claude Code, Codex, Gemini, OpenCode, Cursor Agent or Antigravity CLI, an API key, or local Ollama. Requests go straight to your provider, and every run has a Stop button because I don't trust robots either.
      
          
      Keep scrolling. The rest of this window moves sideways.
      
        
      atomic commits
      
          
      
          
      You did six things and committed none of them. CtrlShiftA hands the mess to the AI, which sorts it into logical commits you can edit, re-roll and approve. A conflict or a paused rebase blocks it before it starts, so it never fails halfway.
      
        
      commit messages
      
          
      
          
      The sparkle in the summary box writes a message in your style: your prefix list, your 50/72, your gitmoji or lack of one.
      
        
      review staged
      
          
      
          
      A second pair of eyes on exactly what you're about to commit, before the commit exists to be embarrassed about.
      
        
      suggest a resolution
      
          
      
          
      Proposes a merged result per conflict, or Suggest all with a progress count and Stop. It lands as an unaccepted ghost preview with Accept, Edit and Discard, a confidence label and a rationale: never auto-applied, never auto-staged.
      
        
      and also
      
          
        
            
      • Explain a conflict. Both sides in plain English: what each branch was trying to do and why they collided. Per file, with Stop.
        • 
            
      • Explain a commit. Inherited a repo with commit messages like "update"? Ask what a commit actually did.
        • 
            
      • PR descriptions. Generated from the commits on the branch. Edit it, paste it, pretend you wrote it at your desk.
        • 
            
      • Agents and orchestration. More in the agents window.
        • 
          
      
          
      Screenshots are the real app in demo mode with canned model replies. Still on the shelf, drafted and not started: AI-assisted autosquash. I'll tell you when it's real. See the roadmap.
      
      
      
    
      
  
      


  
  
      
    
      
      
      gitmo: the ritual without the window
      
      
      
        
      
          
      Four wizards. Zero windows.
      
          
      Since 0.8.0 the command line is a client of its own. gitmo runs headless, so it works over SSH and on a box with no display. Every wizard goes through the same engine as the GUI, so signing, discard checks and worktree guards behave identically in both worlds.
      
          
        
            
      • gitmo commit lists changed files, takes 1,2, a or e, holds the 50/72 line, and prints the oids so git reset --soft is always your undo.
        • 
            
      • gitmo yolo amends HEAD keeping its message, hooks skipped, and refuses when the branch is ahead of its upstream.
        • 
            
      • gitmo discard shows what it will destroy and defaults to No. Nothing is discarded silently, ever.
        • 
            
      • gitmo cleanup fetches, prunes, and pre-checks merged branches in a picker.
        • 
          
      
        
      
        
      
      

      
      
        
        
      
          
      Press Ctrl`.
      
          
      Every repository gets a shell at its own path, right under the graph. It picks up your login environment, so Homebrew, fnm, nvm, volta and mise resolve exactly as they do in your real terminal.
      
          
        
            
      • Split it. CtrlShiftD opens a pane beside it, CtrlShiftW closes one, and the active pane wears a coloured edge so you know where you're typing.
        • 
            
      • Bring agents. Run several as tabs, jump with Alt1…9, and give your favourites a colour and a summon key.
        • 
            
      • Copy like a person. CtrlShiftC and V, and Alt←→ reach the shell so your agent's shortcuts work.
        • 
            
      • Run your palette actions here, or in the background if you'd rather not watch.

      Conventions you don't have to remember.
      
          
      Define up to three prefix lists and the commit box turns them into keyboard dropdowns. Focus the box and the first list opens; pick a value and it hops to the next list, then to the summary. You never leave the keys.
      
          
        
            
      • Searchable. Type to filter a list, type something new to add it, press Esc to skip to the next prefix.
        • 
            
      • Templates. Shape the result with <type>(<scope>):, [<scope>]<type>: or <type>-. Empty lists drop out, and there's a live preview in Settings.
        • 
            
      • Gitmoji, if that's your thing. A curated catalog ships in the box, with one-click Add gitmoji list.
        • 
            
      • Per repository. Selections are remembered for each repo, so the monorepo and the side project stop arguing.
        • 
            
      • Everywhere. The 50/72 counter and the AI both account for the active prefix, and gitmo commit offers the same lists in the terminal (--prefix to skip the picker, --no-prefix to skip them all).
        • 
          
      
        
      
        
      
          
          
          
      Template <type>(<scope>): turns feat and graph into feat(graph): virtualize commit rows.
      
        
      
      
      
    
      
  
      


  
  
      
    
      
      
      Dress it in shadow.
      
      
      Fifteen hand-tuned themes, five accent colours and six graph palettes. This whole page is wearing whichever you pick below, so go on, try one.
      
      
      
        
      
        
      
      
      
      

      
      
        
      
          
      Every project gets its own look.
      
          
      gitmoire wears the repo you're in. Give a project a logo and it follows you around the whole app, so six tabs don't look like six copies of the same tool.
      
          
        
            
      • Logo on the tab and behind the graph. It sits behind the graph with a radial fade, so rows stay readable.
        • 
            
      • The accent follows the logo. Its dominant colour becomes the app accent, locked on by default with a per-repo escape hatch. Diff and graph colours are never touched.
        • 
            
      • Worktrees get their own hue, so eight checkouts of one project read as eight different things.
        • 
            
      • Six lane palettes for the graph: Gitmoire, Dark Magic, Neon, Pastel, Mono and Project, which lifts six colours out of the open repo's own logo.
        • 
          
      
          
      
          
      
        
      
        
      
      

      
      Omarchy
      
      
      
        
      
          
          
      Your desktop, mirrored.
      
          
      On Omarchy, gitmoire can wear your current system theme and follow it when you change it. Surfaces, borders, syntax and the accent all come from the theme's own colour file, so the app looks like it grew up on your machine. These are four stock Omarchy themes, applied to the real UI. New to it? omarchy.org has the whole story.
      
          
      
            
            
            
            
          
      
        
      
        
      
      
      
        
        
      • Accents recolour the interactive bits only. Graph lanes and diff colours keep their meaning, so a green line is still an addition.
        • 
        
      • Switch fast. CtrlShiftT opens a theme switcher without going near settings.
        •
